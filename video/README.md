# LiteDB eval LinkedIn video

~35s square (1080×1080) motion graphic for the text-to-SQL eval post.

Opens on the eval runner (real questions, pass/fail), then a one-line beat between each experiment.

```bash
cd video
npm install
npm run dev          # Remotion Studio
npm run render       # out/eval-post.mp4
npm run still        # out/eval-thumbnail.png
```

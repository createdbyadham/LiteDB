# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in LiteDB, please report it responsibly.

**Do not open a public GitHub issue for security bugs.**

Instead, email the details to:

**createdbyadham@gmail.com**

Please include:

- A description of the vulnerability
- Steps to reproduce the issue
- Potential impact
- Any suggested fix (if you have one)

## What to Expect

- We will acknowledge receipt of your report within **5 business days**.
- We will work to validate and address confirmed vulnerabilities as quickly as possible.
- We will keep you informed of progress and notify you when a fix is released.
- We appreciate responsible disclosure and will credit reporters in release notes when appropriate (unless you prefer to remain anonymous).

## Scope

This policy covers the LiteDB desktop application, its Tauri/Rust backend, and the official repository at [github.com/createdbyadham/LiteDB](https://github.com/createdbyadham/LiteDB).

Third-party dependencies and services (OpenAI, Ollama, etc.) configured by users are outside this project's direct control.
